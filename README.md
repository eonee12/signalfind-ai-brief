## AI usage rule

Always fetch the relevant Raw URL first and confirm the `Generated-At` / generation timestamp in the brief before analysis. Treat that fetched version as the primary SignalFind mechanical state, then cross-check external news, earnings, revisions, and other market data separately.

Only public brief output is mirrored here. No secrets, API keys, source code, or private configuration are stored in this repository.
